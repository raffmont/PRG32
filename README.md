# PRG32 — Archived Repository

This repository is no longer the current development home of PRG32.

## Use the current repository

PRG32 development, documentation, examples, issues, and future fixes are
maintained in the canonical repository:

**[riscv-prg32/PRG32](https://github.com/riscv-prg32/PRG32)**

Please use that repository for:

- the latest source code and firmware;
- current documentation and learning materials;
- new issues, questions, and pull requests;
- updated build, cartridge, and QEMU workflows.

## About this repository

This repository is retained only as a historical snapshot of an earlier PRG32
implementation. It is not maintained and should not be used as the source for
new work. Existing links to this repository should be updated to point to the
canonical repository above.

The project is an educational ESP32/RISC-V gaming platform for teaching
embedded systems, computer architecture, assembly, and C programming.
